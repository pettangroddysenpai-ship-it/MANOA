GPS & Google Earth for the Network

← Back to Index

Definition

GPS (Global Positioning System) is a satellite navigation system that precisely determines the geographic coordinates of a point on Earth. In the context of telecommunications at Matrix Telecom, GPS and Google Earth are used for tower positioning, fiber optic route mapping, customer cartography, and network deployment optimization.

Coordinate Systems

Latitude and Longitude

Latitude measures north-south position relative to the equator (0° to 90° N/S). Longitude measures east-west position relative to the Greenwich meridian (0° to 180° E/W). For Yaoundé, the approximate coordinates are 3°52′N 11°31′E.

UTM (Universal Transverse Mercator)

A cartographic projection system that divides the Earth into 60 zones of 6° longitude each. Yaoundé is located in UTM zone 33N. UTM coordinates are expressed in meters (Easting, Northing), facilitating distance and area calculations.

Coordinate Formats

  • DD (Decimal Degrees): 3.8667°N, 11.5167°E — ideal for Google Earth
  • DMS (Degrees Minutes Seconds): 3°52′00″N, 11°31′00″E — traditional format
  • UTM: 33N 332500E 4275000N — used for field surveys

How It Works

GPS uses a constellation of 31 satellites orbiting at approximately 20,200 km altitude. Each satellite continuously emits a signal containing its position and precise time (atomic clock). The GPS receiver calculates its distance from at least 4 satellites by measuring signal propagation time. Through triangulation, it determines its 3D position (latitude, longitude, altitude) with 2 to 5 meter accuracy under normal conditions.

Google Earth uses satellite imagery, aerial photography, and GIS (Geographic Information System) data to create a 3D model of the Earth. KML/KMZ files allow importing points, lines, and polygons to overlay network information on the map.

Application at Matrix Telecom Yaoundé

Case Study: Fiber Optic Route Mapping

Matrix Telecom deploys fiber optics in the neighborhoods of Yaoundé (Mvan, Nlongkak, Bastos, Mfoundi). Here is how GPS and Google Earth are used:

  1. Field survey: The transmission team walks the neighborhood with a Garmin GPS or smartphone in survey mode. At each intersection, they record a waypoint.
  2. Import into Google Earth: The waypoints are exported as GPX or KML files, then imported into Google Earth Pro.
  3. Route tracing: By connecting the points, a path is created representing the exact cable route. The total distance can be measured.
  4. Infrastructure addition: ODF cabinets, connection points, and customers are added as placemarks with their exact coordinates.
  5. Map export: The final KMZ map is shared with maintenance and sales teams.

Result: A complete map of Matrix's fiber network in Yaoundé, viewable by all technicians on Google Earth.

Tower and Antenna Positioning

To install a new WiFi tower or point-to-point antenna, the following steps are performed:

  • Line of Sight (LoS): Verification on Google Earth using the elevation tool to ensure no obstacles (hills, buildings) block the signal.
  • Precise coordinates: GPS survey at the installation point to document the exact location.
  • Distance measurement: Using the ruler tool in Google Earth to verify link range.
  • Planning: Creating a KML overlay with radio links, azimuth angles, and distances.

Tools Used

Google Earth Pro (free)
Usage:
  • Download from google.com/earth/about/versions/
  • Create a new project: File > New > Folder
  • Add a placemark: yellow pin icon, enter coordinates in DD or DMS
  • Draw a path: path icon, click on the map to define points
  • Measure a distance: ruler icon, click on two points
  • View elevation profiles: right-click on a path > Show Elevation Profile
  • Export to KMZ: File > Save > Save Place As
GPS Waypoint Recorder
Usage:
  • Turn on the GPS and wait for synchronization (at least 4 satellites)
  • Mark a point: press the MARK/SAVE button
  • Name the point with a unique identifier (e.g., FIBRE-MVAN-001)
  • Record the displayed coordinates in the field notebook
  • Transfer data via USB or SD card in GPX format
QGIS (open-source)
Usage:
  • Create a project with the WGS 84 coordinate system (EPSG:4326)
  • Import GPX survey data: Layer > Add Layer > Add GPX Layer
  • Add OpenStreetMap basemaps: Web > QuickMapServices > OSM
  • Create vector layers for cables, cabinets, and customers
  • Use the field calculator for distance formulas
  • Export to KML for Google Earth

Commands and Practical Examples

Coordinate Conversion DMS → DD

Formula: DD = Degrees + (Minutes / 60) + (Seconds / 3600)

# Example Yaoundé 3°52'00"N 11°31'00"E
Latitude DD = 3 + 52/60 + 00/3600 = 3.8667°N
Longitude DD = 11 + 31/60 + 00/3600 = 11.5167°E

Distance Calculation Between Two Points (Haversine Formula)

a = sin²(Δlat/2) + cos(lat1) · cos(lat2) · sin²(Δlon/2)
c = 2 · atan2(√a, √(1-a))
d = R · c  (R = 6371 km)

# Between Matrix Bastos (3.85N, 11.50E) and Matrix Mvan (3.78N, 11.53E)
Δlat = 3.78 - 3.85 = -0.07° = -0.001222 rad
Δlon = 11.53 - 11.50 = 0.03° = 0.000524 rad
a = sin²(-0.000611) + cos(3.85°) · cos(3.78°) · sin²(0.000262)
  = 3.73e-7 + 0.998 · 0.998 · 6.86e-8
  = 4.41e-7
c = 2 · asin(√4.41e-7) = 0.00133 rad
d = 6371 · 0.00133 = 8.47 km

Tip for the Intern

Tip:
  • Always verify that the GPS is calibrated and picking up at least 4 satellites before taking a reading.
  • Record coordinates on paper in addition to the digital recording — batteries can fail.
  • In Google Earth, use satellite image history to see infrastructure evolution.
  • Create thematic folders in Google Earth: one for fiber, one for radio links, one for customers.
  • Learn keyboard shortcuts: Ctrl+N (new placemark), Ctrl+T (new path), Ctrl+M (measure).
  • For precise surveys (< 1 m), use a differential GPS (DGPS) or RTK mode.
  • Check survey accuracy: GPS displays an error margin (HDOP). An HDOP < 1 is excellent.
  • Name placemarks in a standardized way: SITE-DISTRICT-TYPE-NUMBER (e.g., FIB-BASTOS-ODF-01).

Exercise

Task 1: Survey a Fiber Route with a Handheld GPS and Export to Google Earth

Before trenching fiber, Matrix field teams walk the route with a GPS to record waypoints of manholes, poles, and street crossings. This data is imported into Google Earth for route planning. This task simulates the survey workflow using a GPS device or smartphone app.

  1. Set the GPS device to WGS 84 coordinate system and enable tracking (track every 5 meters).
  2. Walk the planned route: mark waypoints at each manhole, pole, and road crossing with descriptive names (e.g., "MH-Bastos-01", "POLE-Nlongkak-03").
  3. After the walk, export the track and waypoints as GPX and KML files.
  4. Open Google Earth Pro on a PC and import the KML file: File > Open.
  5. In Google Earth, create a folder for the project and organize waypoints into subfolders by street segment.
  6. Add a path (polyline) tracing the fiber route, using the track as reference. Set the path color to blue with 50% opacity.
  7. Add a photo of each significant landmark (attach to its placemark) for the civil works team to reference.
  8. Save the project as a KMZ file and share with the installation team.

Task 2: Measure and Validate GPS Coordinates for a New Site Survey

Accuracy matters: a 10-meter error in GPS coordinates can lead to digging in the wrong location. Matrix requires that all site coordinates are validated against known reference points. This task teaches GPS accuracy verification.

  1. At the survey site, allow the GPS receiver to acquire at least 6 satellites (check satellite page on the device).
  2. Stand at the exact location (e.g., the POP entrance) and let the GPS stabilize for 2-3 minutes.
  3. Record the coordinates in degrees decimal format (DD.DDDDD) and note the HDOP (Horizontal Dilution of Precision) — must be < 2.
  4. Save the waypoint and move 10 meters north, then re-record. The difference should be approximately 0.00009° in latitude.
  5. Cross-check with Google Earth: enter the coordinates in the search bar and verify the pin falls on the correct building.
  6. If the pin is more than 5 meters off, re-survey the location. If consistent, note a correction offset in the survey log.
  7. Document the final coordinates in the site database with the date and HDOP value.

Best Practices

  • Use the WGS 84 coordinate system (EPSG:4326) for all surveys.
  • Save surveys in GPX format (standard) rather than proprietary.
  • Back up KML/KMZ files in the cloud.
  • When tracing fiber routes, follow roads and sidewalks in Google Earth for a realistic path.
  • Use Google Earth layers (traffic, relief, 3D buildings) for better planning.
  • Train field teams in GPS and Google Earth usage to ensure data quality.
