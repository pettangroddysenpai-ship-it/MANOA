IP Video Surveillance

← Back to Index

Definition and Detailed Explanation

An IP video surveillance system uses digital cameras that transmit video streams over an IP network, unlike traditional analog systems (coaxial CCTV). Each IP camera is a full-fledged network device with its own IP address, embedded web server, and processing capability.

At Matrix Telecom, video surveillance is offered as a complementary service to business customers, including installation, configuration, and remote monitoring via Matrix's network.

Advantages of IP systems over analog:

  • High resolution: HD (720p), Full HD (1080p), 2K, 4K, even 8K
  • PoE power: Single Ethernet cable for video, control, and power
  • Remote access: Viewing from anywhere via Internet (smartphone, PC)
  • Built-in intelligence: Motion detection, facial recognition, AI video analysis
  • Integration: Can be integrated with access control, alarm, and fire systems
  • Scalability: Adding cameras without additional infrastructure

How It Works

IP Video Surveillance System Architecture

A typical system consists of:

  • IP Cameras: Box (dome, bullet, PTZ), variable resolution, with or without microphone, infrared night vision.
  • NVR (Network Video Recorder): Server that records video streams from cameras. Hikvision, Dahua, and UniFi NVRs manage continuous recording, motion detection, or scheduled recording.
  • PoE Switch (Power over Ethernet): Network switch that powers cameras via Ethernet cable (IEEE 802.3af/at/bt standard). Delivers up to 30W per port (PoE+) or 60-90W (PoE++).
  • Storage: Specialized hard drives for video surveillance (WD Purple, Seagate SkyHawk) optimized for continuous writing (24/7).
  • Network: Dedicated VLAN for video traffic, QoS to guarantee priority.

ONVIF Standard

ONVIF (Open Network Video Interface Forum) is an open standard that guarantees interoperability between video surveillance equipment from different manufacturers. An ONVIF camera can be connected to any ONVIF NVR.

Common ONVIF profiles:

  • Profile G: Basic recording and streaming
  • Profile Q: Quick configuration (plug-and-play)
  • Profile S: Standard video streaming
  • Profile T: Advanced streaming, events, two-way audio
  • Profile A: Access control

Power over Ethernet (PoE)

PoE significantly simplifies deployment:

  • IEEE 802.3af (PoE): Up to 15.4W per port. Sufficient for standard fixed cameras.
  • IEEE 802.3at (PoE+): Up to 30W per port. For PTZ (Pan/Tilt/Zoom) cameras with heating.
  • IEEE 802.3bt (PoE++): Up to 60-90W (Type 3/4). For high-performance cameras with advanced features.

Maximum distance: 100 meters (Cat5e or Cat6 copper cable). Beyond that, use PoE extenders or intermediate switches.

Storage Calculation

Required storage depends on:

  • Number of cameras
  • Resolution (Megapixels)
  • Codec (H.264 vs H.265: H.265 reduces bandwidth by 40-50%)
  • FPS (frames per second)
  • Desired retention period

Example: 1 camera at 2MP (1080p) in H.265 at 15 FPS uses ~1-2 GB per day. 16 cameras for 30 days = 16 × 1.5 GB × 30 = 720 GB.

Tools Used

Hikvision SADP Tool — Hikvision camera discovery and configuration
Windows tool that scans the local network to find all Hikvision cameras and NVRs. Allows resetting passwords, updating firmware, configuring IP addresses.
Usage:
1. Download SADP from hikvision.com
2. Launch the application (network must be in admin mode)
3. Click "Refresh" to scan
4. Select a camera
5. Configure the IP address in the same subnet as the NVR
6. Enter the admin password to apply changes
7. Enable ONVIF protocol in the network settings
Dahua ConfigTool — Dahua camera configuration
Similar to SADP but for the Dahua ecosystem. Allows batch configuration (multiple cameras at once).
Usage:
1. Download ConfigTool from dahua.com
2. Launch and scan the network
3. Select cameras to configure
4. Modify IP, mask, gateway, password
5. Apply to all selected cameras

# Web access to a Dahua camera

Password: set at activation

Tip for the Intern:
1. Always separate video traffic in a dedicated VLAN to avoid congestion on the main network.
2. Default camera passwords are a major security vulnerability. Change them systematically.
3. Calculate required storage BEFORE sizing the NVR. Use online calculators (e.g., Hikvision Storage Calculator).
4. For outdoor use, check the camera's IP rating (IP67), UV resistance, and operating temperature.
5. For cabling, prefer Cat6 (up to 10 Gbps) to be compatible with future upgrades.
6. At Matrix, ask to see existing video surveillance installations. You will see the network infrastructure behind the cameras.
7. For troubleshooting: first check PoE (is the camera LED on?), then IP (ping), then web access, then the NVR.

Exercise

Task 1: Configure an NVR and Add IP Cameras Over the Network

Matrix Telecom deploys IP video surveillance for clients using NVRs and PoE cameras. This task simulates adding cameras to an NVR, assigning IPs, and verifying the video feed — a common field deployment scenario.

  1. Connect the NVR to the client LAN and configure a static IP (e.g., 192.168.200.10/24).
  2. Log into the NVR web interface (default credentials from the manual) and go to Camera Management.
  3. Connect a PoE camera to the same PoE switch and note its MAC address.
  4. Use the NVR's Auto-Discovery tool to find the camera. If not found, add it manually by IP.
  5. Assign the camera an IP in the same subnet and set the admin password (change from default).
  6. Configure recording: set schedule to continuous, motion detection, or event-based per the client's needs.
  7. Verify the live feed appears in the NVR interface and test playback of a recorded clip.
  8. Access the camera directly via web browser at its IP to confirm standalone access works.

Task 2: Calculate Storage Requirements and Configure Retention

A common mistake is undersizing NVR storage. At Matrix, you must calculate how many days of footage can be stored based on camera count, resolution, and frame rate. This task walks through the calculation and NVR configuration.

  1. Assume 8 cameras: 4x 2MP (H.265) at 15 fps, 4x 5MP (H.265) at 10 fps.
  2. Use the Hikvision storage calculator formula: bitrate (Mbps) = resolution factor × fps / 1024 × compression ratio.
  3. Alternatively, use an online calculator (e.g., https://www.hikvision.com/en/support/calculator/) with the above parameters.
  4. Determine the daily storage in GB for all 8 cameras, then calculate for 30 days of retention.
  5. Log into the NVR, go to Storage > Schedule Settings and set the recording bitrate and frame rate.
  6. Check the NVR's current disk space (e.g., 2 TB HDD) and confirm it supports the 30-day requirement.
  7. If the disk is insufficient, advise the client on upgrading to a larger HDD or reducing retention days.
