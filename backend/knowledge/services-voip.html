VoIP — Voice over IP

← Back to Index

Definition and Detailed Explanation

VoIP (Voice over Internet Protocol) is a technology that transmits human voice as digital data packets over an IP network, instead of through the traditional circuit-switched telephone network (PSTN). Voice is sampled, compressed, encapsulated in IP packets, and transmitted in real time.

At Matrix Telecom, VoIP is a strategic service for businesses, offering significant cost savings on calls (especially international) and advanced features: auto attendant, voicemail, conference calling, CRM integration, and much more.

How It Works

Fundamental Protocols

SIP (Session Initiation Protocol) is the dominant signaling protocol for VoIP. It manages the establishment, maintenance, and termination of call sessions. SIP uses text-based messages (like HTTP):

  • INVITE: Initiates a call
  • ACK: Confirms receipt of a final response
  • BYE: Terminates a call
  • REGISTER: Registers a user with the server
  • CANCEL: Cancels a call being established
  • OPTIONS: Checks server or client capabilities

RTP (Real-time Transport Protocol) transports audio or video data. It works over UDP to minimize latency. RTP packets contain:

  • A header with sequence number and timestamp for reassembly
  • The compressed audio payload (codec G.711, G.729, G.722, Opus)

Audio Codecs

Codecs compress voice to save bandwidth:

  • G.711: No compression, 64 kbps, maximum quality (A/u law)
  • G.729: CS-ACELP compression, 8 kbps, good audio quality but requires licenses
  • G.722: Wideband audio (HD Voice), 64 kbps, superior quality
  • Opus: Free codec, adaptable from 6 to 510 kbps

VoIP Network Architecture

A typical VoIP infrastructure includes:

  • IP PBX (Private Branch Exchange): Central server that manages calls (Asterisk, FreePBX, 3CX, Cisco Call Manager). It routes calls between extensions, to the PSTN network (via a gateway), and to other SIP carriers.
  • VoIP Gateway: Bridge between the IP network and the traditional telephone network (PSTN). ATA (Analog Telephone Adapters) like the PAP2T or Grandstream HT801 convert an analog phone into an IP device.
  • Session Border Controller (SBC): Security element that protects the VoIP network from attacks and manages NAT/firewall traversal.
  • IP Phones: Digital phones that connect directly to the IP network (Cisco 7841, Yealink T4x, Polycom VVX).
  • Softphones: Software applications that emulate a phone on a PC or smartphone (Zoiper, Linphone, MicroSIP).

SIP Call Process

  1. Phone A sends an INVITE sip:number@matrix.cm to its SIP server.
  2. Matrix's SIP server resolves the recipient's address (via directory or routing).
  3. The server sends INVITE to phone B or to the PSTN via the gateway.
  4. Phone B rings and sends 180 RINGING.
  5. User B answers: 200 OK.
  6. RTP media exchange between both endpoints.
  7. User A hangs up: BYE then 200 OK.

Practical Example at Matrix Telecom

Example: Matrix deploys a VoIP solution for a customer company with 50 employees. This company has 3 outbound numbers and an auto attendant.

Configuration excerpt (Asterisk extensions.conf):
[default]
exten => _X.,1,Dial(SIP/${EXTEN}@provider,30)
exten => _X.,n,Hangup()

[internal]
exten => 100,1,Answer()
exten => 100,n,Playback(welcome)
exten => 100,n,WaitExten(10)

exten => 200,1,Dial(SIP/200)
exten => 201,1,Dial(SIP/201)
exten => 202,1,Dial(SIP/202)

[outbound]
exten => _0XXXXXXXXX,1,Dial(SIP/${EXTEN:1}@matrix-trunk)
exten => _00.,1,Dial(SIP/${EXTEN}@matrix-intl)
The company benefits from free internal calls, reduced-rate national calls, and an interactive voice response (IVR) system for customer service.

Tools Used

Wireshark — SIP and RTP frame analysis
Allows capturing and analyzing SIP signaling and RTP media streams to diagnose quality or connection issues.
Usage:
# Filter SIP traffic
sip

# Filter RTP traffic
rtp

# Filter a specific SIP conversation
sip.Call-ID == "xyz123@192.168.1.1"

# Analyze voice quality with Wireshark:
Telephony > VoIP Calls > Select the call
Telephony > RTP > Show All Streams
# Check: jitter, packet loss, MOS (Mean Opinion Score)
FreePBX Admin — PBX administration interface
Web interface for managing the Asterisk/FreePBX server.
Usage:
# Access the interface
http://server-ip:80

# Login information
User: admin
Password: defined during installation

# Common tasks:
Applications > Extensions: Add an extension
Connectivity > Trunks: Configure the SIP trunk
Connectivity > Outbound Routes: Outbound routing
Connectivity > Inbound Routes: Inbound routing
Admin > Asterisk CLI: Real-time commands
PAP2T Configuration — Linksys PAP2T ATA
Analog telephone adapter for connecting traditional phones to the VoIP network.
Usage:
# Configuration via web interface
http://192.168.1.100 (default address: 192.168.15.1)

# SIP settings
Line 1 - Proxy: sip.matrix.cm
Line 1 - Display Name: Customer Service
Line 1 - User ID: 237123456789
Line 1 - Password: ********
Line 1 - Auth ID: 237123456789
Line 1 - Use Outbound Proxy: yes
Line 1 - Outbound Proxy: sbc.matrix.cm
Line 1 - Register Expires: 3600
Line 1 - Preferred Codec: G.711u

Asterisk CLI — Asterisk command line interface
Usage:
# Connect to the Asterisk console
asterisk -rvvv

# Useful commands
sip show peers                    # Show registered SIP peers
sip show channels                 # Show active SIP channels
queue show                        # Show queues
core show channels                # Show active channels
core show calls                   # Show calls in progress
pjsip show endpoints              # With PJSIP (Asterisk 13+)
module show                        # List loaded modules
reload                            # Reload configuration

Tip for the Intern:
1. Install a FreePBX instance on a VM to learn how to configure extensions, trunks, and routing rules.
2. Download a softphone (Zoiper, MicroSIP) and register it on the test PBX.
3. Learn to read a SIP capture in Wireshark: identify INVITE, 200 OK, BYE, REGISTER messages.
4. Understand codecs: why G.729 is useful on low-bandwidth links.
5. At Matrix, VoIP quality depends on network quality: jitter > 30ms or loss > 1% degrades the call.
6. Ask your supervisor: how does Matrix interconnect its PBX with national telephone operators (Camtel, Orange, MTN)?
