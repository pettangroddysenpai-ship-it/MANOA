TP-Link / Linksys (Small Business)

← Back to Routing Guide

Definition

TP-Link and Linksys are manufacturers of network equipment aimed at consumers and small/medium businesses. Their routers are known for their ease of configuration via web interface, affordable cost, and reliability. The most common ranges at Matrix Telecom are TP-Link Archer (Wi-Fi AC/AX), TL-WR841N, TL-MR3420 and Linksys EA/E series.

What are TP-Link and Linksys used for at Matrix Telecom?

These routers are mainly used for SOHO (Small Office / Home Office) clients. Unlike MikroTik which are more complex but more powerful, TP-Link and Linksys offer quick setup and an intuitive user interface. Matrix deploys them for clients who do not need advanced features (complex QoS, VPN, VLANs).

How It Works

Router Mode (default)

The router acts as a gateway between the local network (LAN) and the Internet (WAN). It performs NAT (Network Address Translation) to allow multiple devices to share a single public IP address. The built-in DHCP server distributes local IP addresses.

Access Point Mode

In this mode, the router acts as an Ethernet switch + Wi-Fi access point. It does not perform NAT or routing. It is connected to an existing main router. Useful for extending Wi-Fi coverage in an office.

Repeater / Range Extender Mode

The router captures the existing Wi-Fi signal and retransmits it. Useful for covering dead zones. Note: bandwidth is reduced by half.

Step-by-Step Configuration

Step 1: Accessing the Web Interface

Connect your PC to a LAN port on the router. Open a browser and type the router's default IP address:

  • TP-Link : http://192.168.0.1 or http://tplinkwifi.net
  • Linksys : http://192.168.1.1 or http://myrouter.local

Default credentials: admin / admin (or the credentials on the router's label).

Step 2: Internet (WAN) Configuration

  1. Go to "Network" > "WAN" or "Internet".
  2. Select the connection type: Dynamic IP (DHCP), PPPoE (ISP), Static IP.
  3. For PPPoE, enter the username and password provided by Matrix.
  4. Click "Save" or "Connect".

Step 3: Wi-Fi Configuration

  1. Go to "Wireless" > "Basic Settings".
  2. Choose the SSID (network name), for example "Matrix-Client42".
  3. Disable WPS (not secure).
  4. Go to "Wireless Security".
  5. Choose WPA2-PSK or WPA3-PSK if available.
  6. Set a strong password (12 characters minimum, letters + numbers + symbols).
  7. Save. The router will reboot.

Step 4: DHCP Configuration (optional)

  1. Go to "Network" > "DHCP Server".
  2. Address range: for example 192.168.0.100 to 192.168.0.200.
  3. Lease time: 1 day (1440 minutes) for clients.
  4. Gateway: the router's IP (192.168.0.1).
  5. DNS: 8.8.8.8, 1.1.1.1 or Matrix DNS.

Step 5: Port Forwarding

To allow access to internal services from the Internet (web server, IP camera, etc.):

  1. Go to "Forwarding" > "Virtual Servers" (TP-Link) or "Security > Apps & Gaming" (Linksys).
  2. Add a rule: External port 80 → Local IP 192.168.0.10 port 80 (HTTP).
  3. Save.

Practical Example at Matrix Telecom

Use Case: Deploying a TP-Link Archer AX73 for a small neighborhood shop in Yaoundé.

Client need: 30 Mbps Internet, Wi-Fi for 10 employees and a network printer.

Procedure:
  1. The Matrix technician arrives at the client's location with a pre-configured router.
  2. He connects the fiber/ADSL cable to the WAN (blue) port of the router.
  3. He connects to the web interface via a smartphone or laptop.
  4. He configures the WAN connection type: PPPoE with Matrix credentials.
  5. He sets the SSID "Matrix-Boutique-A" with WPA2 password.
  6. He tests the Internet connection on a client workstation.
  7. He records the connection details (router IP, PPPoE ID, SSID/Wi-Fi password) in the client file.

Specific settings:
  • The DHCP range is limited to 15 addresses (192.168.0.100-114) to avoid exhaustion.
  • The built-in firewall (SPI) is enabled in "Security".
  • The firmware is updated before deployment.
  • Access to the administration interface is restricted to local IPs.

Tools Used

Web Interface - Access via browser (Chrome, Firefox, Edge). Allows full router configuration.
Usage: Type the router's IP in the address bar.

Firmware Update - Updating the router's internal software. Essential for security and performance.
Usage: Download the firmware from the official site (TP-Link or Linksys Support), go to "System Tools > Firmware Upgrade", select the .bin file and click Upgrade. Never cut power during the update.

TP-Link Tether (mobile app) - Android/iOS app to configure TP-Link routers from a smartphone. Useful for quick deployments.
Usage: Connect the smartphone to the router's Wi-Fi or via Bluetooth, launch the app and follow instructions.

Linksys App - Mobile app for Linksys routers. Quick setup via wizard.
Usage: Download from the store, create a Linksys Smart Wi-Fi account if needed.

PuTTY (telnet/SSH) - Some professional TP-Link routers (TL-ER6020, etc.) support command line access.
Usage: ssh admin@192.168.0.1

Advantages and Limitations

  • Advantages: Affordable price, intuitive configuration, reliable, good Wi-Fi performance for standard use.
  • Limitations: Limited advanced features (basic QoS, no BGP/OSPF, limited VPN), less suited for large deployments.
  • No centralized management: each router is configured individually.
  • Limited log management, no advanced SNMP monitoring.

Tip for the Intern

Good to know:
  • TP-Link/Linksys routers are simpler than MikroTik but have their own specifics. Take the time to read the model's manual.
  • Always check the firmware version before deployment. Outdated firmware may have security vulnerabilities.
  • Note the default IP address of the router (192.168.0.1 or 192.168.1.1). If it conflicts with the client's network, change it.
  • For SOHO deployments, these routers are the ideal choice. For clients with evolving needs, recommend a MikroTik.
  • If the password is forgotten, the reset button (10 seconds) restores factory settings.
  • The QoS on these routers is basic but sufficient to limit a client's bandwidth.

Troubleshooting

  • No access to web interface: Check your PC's IP (it must be in the same subnet as the router). Try pinging the router's IP.
  • No Internet connection: Check the LED indicators (Power, WAN, LAN). Check the WAN connection type and PPPoE credentials.
  • Slow Wi-Fi: Change the Wi-Fi channel (1, 6 or 11 for 2.4 GHz). Move the router away from interference sources (microwaves, cordless phones).
  • Some sites won't open: Check the configured DNS. Switch to 8.8.8.8 / 1.1.1.1.
  • Router rebooting in a loop: Power supply issue or corrupted firmware. Try a factory reset and firmware reinstall via recovery mode.

Best Practices

  • Disable WPS (known vulnerability).
  • Change the default SSID and password.
  • Enable SPI firewall (Stateful Packet Inspection).
  • Limit admin access to local IPs only.
  • Update firmware regularly.
  • Disable UPnP if not needed (security risk).
