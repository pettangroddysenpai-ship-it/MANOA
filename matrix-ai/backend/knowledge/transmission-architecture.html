Physical Architecture of an Installation

← Back to Index

Definition

The physical architecture of a network installation describes how equipment is organized, interconnected, and physically arranged in a technical room or datacenter. At Matrix Telecom, a well-designed architecture ensures reliability, maintainability, and network scalability.

Network Hierarchy

The typical architecture at Matrix Telecom follows a multi-level hierarchical model:

                   [Main POP]
                        |
                   [Core Router]
                        |
                   [Distribution Switch]
                       / \
                      /   \
          [Access Switch]  [Access Switch]
               |                    |
            [Client]             [Client]

1. POP (Point of Presence)

The POP is Matrix's central point of presence in a geographic area. It contains core network equipment, OLTs for fiber, microwave antennas, and Internet links. See the « POP Infrastructure » page for more details.

2. Core Router

The core router provides connectivity between POPs and the Internet backbone. It handles BGP routing, IP prefix announcements, and high-speed traffic. Typical hardware: Cisco ASR 1000, MikroTik CCR1036, Juniper MX204.

3. Distribution Switch

The distribution switch aggregates traffic from access switches and forwards it to the core router. It supports VLAN tagging (802.1Q), spanning tree (RSTP/MSTP), and link aggregation (LACP). Typical equipment: Cisco Catalyst 3850, MikroTik CRS328, HP Aruba 2930F.

4. Access Switch

The access switch is the equipment that customers connect directly to. It provides Ethernet ports (1 Gb/s or 10 Gb/s) and applies security policies (port security, ACL, DHCP snooping). Typical equipment: Cisco Catalyst 2960, MikroTik CSS326, Ubiquiti EdgeSwitch.

5. Client (ONU/ONT, Router)

The customer terminal equipment: ONT for fiber, NanoStation for wireless, 4G/5G router, or xDSL modem. It is the termination point of the Matrix network at the subscriber premises.

Rack Organization

A standard rack (42U) at Matrix is organized as follows:

Position (U) Equipment Function
U1 - U4 Fiber patch panel (ODF) Fiber optic connection
U5 - U6 Copper patch panel RJ45 cable connection
U7 - U10 GPON OLT (e.g., Huawei MA5800) Fiber subscriber management
U11 - U14 Distribution switch Traffic aggregation
U15 - U18 Core router Routing and Internet connectivity
U19 - U20 Management panel (KVM, console) Management access
U21 - U22 UPS / PDU Power supply
U23 - U25 Servers (DHCP, AAA, monitoring) Network services
U26 - U27 Batteries Power backup
U28 - U42 Free / future expansion Reserve

Cabling Rules

  • Front side: Short and organized RJ45 patch cords. Use different colored cables per VLAN/traffic type.
  • Rear side: Power cables and fiber optics, secured with velcro straps.
  • Current separation: Electrical cables (220V) and network cables (RJ45/fiber) must be separated.
  • Patch length: Use cables of appropriate length (no coiled excess).
  • Labeling: Every cable must be labeled at both ends with a unique identifier.
  • Fiber management: Optical cables must not be bent (bend radius > 30 mm).

Power and Cooling

Electrical Power

Each POP rack consumes between 2 and 8 kW depending on equipment density. Requirements:

  • Redundant power (dual power supply on each device)
  • PDU (Power Distribution Unit) with per-outlet consumption monitoring
  • UPS sized for 30 minutes of autonomy
  • Generator for critical sites
  • Surge protection via lightning arrestors

Cooling

  • Ideal temperature: 18-25°C
  • Relative humidity: 40-60%
  • Airflow: hot aisle / cold aisle
  • Precision cooling (InRow, CRAC) with hotspot detection
  • For small POPs: rack fans and wall-mounted air conditioners

Cabling Best Practices

Ethernet Cables (RJ45)

  • Cat5e: up to 1 Gb/s (100 MHz) — used for legacy connections
  • Cat6: up to 10 Gb/s (250 MHz) over 55 m — standard for new deployments
  • Cat6a: up to 10 Gb/s (500 MHz) over 100 m — recommended for critical links
  • Cat7 / Cat8: 40 Gb/s — used in datacenters

Optical Cables

  • Single Mode Fiber (OS2): yellow, up to 100+ km, SC/APC connectors (green)
  • Multi Mode Fiber (OM3/OM4): aqua, up to 400 m, LC/UPC connectors (blue)
  • Pigtails: short cables with connector to be spliced onto main cable fibers
  • Adapters: SC-SC, SC-LC, LC-LC for patching in the ODF

Tools Used

Label Printer
Usage:
  • Print heat-resistant labels for each cable
  • Standard format: [SITE]-[EQUIPMENT]-[PORT]-[DESTINATION]
  • Example: MVA-CORE-Gi0-01->MVA-DIST-Po1
  • Models: Brother P-Touch, Dymo LabelWriter, Brady BMP21
Cable Tester
Usage:
  • Test RJ45 cable continuity
  • Verify wiring (T568A / T568B)
  • Detect crossed pairs, short circuits, open cables
  • Measure cable length (TDR)
  • Models: Fluke Networks MicroScanner, Klein Tools VDV501, NetScout LinkRunner
# Cable test with MicroScanner
1. Connect the main unit to one end
2. Connect the remote to the other end
3. Read the result:
   - All green pins = good cable
   - Pin X red = pair X defective
   - Displayed length = measured distance
Rack Layout Software
Usage:
  • Plan the location of each equipment in the rack
  • Calculate power consumption and cooling requirements
  • Document the rack for future interventions
  • Tools: netTerrain, Sunbird DCIM, draw.io, Microsoft Visio
  • Simple template: Excel sheet with U positions
Electrical Multimeter
Usage:
  • Check mains voltage (220-240V AC)
  • Measure battery voltage (48V DC in telecom)
  • Verify power cable continuity
  • Models: Fluke 87V, Uni-T UT61E

Practical Case at Matrix Telecom Yaoundé

Standard Matrix POP Architecture

Here is the standard architecture installed by Matrix Telecom:

  • Location: Each POP is installed in a rented 10-20 m² room (e.g., building in Bastos, Mvan, Nlongkak)
  • 42U Rack: Closed rack with glass door and roof fans
  • Core Router: MikroTik CCR1072-1G-8S+ with 72 cores, 8 SFP+ 10G ports
  • Distribution Switch: MikroTik CRS328-24P-4S+RM (24 PoE ports, 4 SFP+)
  • OLT: Huawei MA5800-X15 with 2 GPON cards (128 max subscribers)
  • ODF: 48-port SC/APC front panel
  • Power: APC Smart-UPS 3000VA + 2 external batteries
  • Cooling: 9000 BTU wall-mounted AC set to 22°C
  • Cabling: Shielded Cat6a cables, organized in cable trays
  • Security: Reinforced door, IP camera, smoke detector, intrusion alarm

Installation Procedure

  1. Preparation: Check electrical power (220V, redundant outlets), rack location, cooling
  2. Rack mounting: Install leveling brackets, cable trays
  3. Equipment installation: Mount equipment from bottom to top (heaviest at bottom)
  4. Cabling: Run cables, crimp connectors, label each cable
  5. Power: Connect power supplies to PDUs, check voltages
  6. Power on: Turn on equipment one by one, check LEDs
  7. Testing: Test connectivity, throughput, latency
  8. Documentation: Create rack diagram (U positions, references), label the rack

Tip for the Intern

Tip:
  • Always label cables at BOTH ends before connecting them. An unlabeled cable becomes a problem after 6 months.
  • Do not tighten velcro straps too hard on RJ45 cables (pair deformation = performance loss).
  • Plan 30% free space in the rack for future expansion.
  • Use horizontal cable managers between each row of equipment.
  • For RJ45 cables, use the T568B standard (standard in most installations).
  • Document immediately after installation. Memory is not reliable.
  • Check ground continuity on each rack. It is a safety issue.
  • A well-organized rack is easier to maintain: interventions are faster and less risky.
  • Learn to read a network architecture diagram and update it after each modification.

Installation Checklist

[] Rack fixed and leveled
[] Electrical power verified (220-240V)
[] UPS connected and charging
[] All equipment mounted in rack
[] RJ45 cables tested and labeled
[] Fiber cables tested (continuity + loss)
[] Grounding verified
[] Cooling operational (target temperature)
[] Rack diagram completed
[] Rack photo taken for documentation
[] Network connectivity verified (ping, iperf)
