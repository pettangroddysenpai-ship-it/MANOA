1. VPN (Virtual Private Network)

Un VPN est un tunnel chiffré créé au-dessus d'un réseau public (Internet) pour sécuriser les communications entre deux points.

Types de VPN

TypeDescriptionUsage
Site-to-SiteInterconnexion de deux réseaux locauxEntreprise avec plusieurs succursales
Remote AccessConnexion individuelle au réseauTélétravail, employés nomades
Client-to-SiteSimilaire à Remote AccessVPN SSL/OpenVPN

2. Protocoles VPN

2.1 IPSec (Internet Protocol Security)

Protocole de sécurité pour IP. Chiffrement fort. Deux modes :

  • Transport Mode : Chiffre uniquement le payload
  • Tunnel Mode : Chiffre tout le paquet (utilisé pour Site-to-Site)

Composants : AH (Authentication Header) + ESP (Encapsulating Security Payload) + IKE (Internet Key Exchange)

2.2 GRE (Generic Routing Encapsulation)

Protocole de tunneling léger. Ne chiffre pas le trafic, mais peut être combiné avec IPSec pour la sécurité.

2.3 OpenVPN

VPN open-source utilisant SSL/TLS. Flexible et facile à configurer.

2.4 WireGuard

VPN moderne, rapide et léger. Chiffrement moderne (ChaCha20).

3. MPLS (Multiprotocol Label Switching)

MPLS est une technologie de backbone privé utilisée par les opérateurs télécoms. Il crée un réseau privé virtuel performant.

┌──────────────────────────────────────────────────────────────┐ │ RÉSEAU MPLS - MATRIX TELECOM │ └──────────────────────────────────────────────────────────────┘ ┌─────────┐ ┌─────────┐ │ Site A │ │ Site B │ │Yaoundé │ │ Douala │ └────┬────┘ └────┬────┘ │ │ ┌────▼──────────┐ MPLS Backbone ┌─────────▼────┐ │ PE Router │◄────────────────────────────►│ PE Router │ │ (Yaoundé) │ ┌─────┐ ┌─────┐ │ (Douala) │ └───────────────┘ │ P │────│ P │ └──────────────┘ │Rtr │ │Rtr │ └─────┘ └─────┘ Label Switched Path (LSP): A → PE(Yde) → P → P → PE(Dla) → B

Concepts clés MPLS

  • Labels : Étiquettes de 32 bits ajoutées aux paquets
  • PE (Provider Edge) : Routeur d'entrée/sortie du backbone
  • P (Provider) : Routeur core du backbone
  • CE (Customer Edge) : Routeur côté client
  • VRF : Virtual Routing and Forwarding (isolation de routage)
  • LDP : Label Distribution Protocol

4. Configuration MikroTik - IPSec VPN

# IPSec VPN Site-to-Site sur MikroTik
/ip ipsec proposal
set [ find default=yes ] auth-algorithms=sha256 \
    enc-algorithms=aes-256-cbc lifetime=8h pfs-group=modp2048

/ip ipsec peer
add exchange-mode=main-l2tp send-initial-contact=yes \
    local-address=198.51.100.1

/ip ipsec profile
set [ find default=yes ] hash-algorithm=sha256 \
    enc-algorithm=aes-256 dh-group=modp2048 lifetime=1d

/ip ipsec policy
add src-address=10.10.1.0/24 dst-address=10.10.2.0/24 \
    tunnel=yes peer=peer1 action=encrypt
