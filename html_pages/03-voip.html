1. Définition

VoIP (Voice over Internet Protocol) est la technologie permettant de transmettre des appels téléphoniques via un réseau IP (Internet ou réseau privé) au lieu du réseau téléphonique classique (PSTN).

Avantages de la VoIP

  • Coût réduit (appels gratuits ou à faible coût)
  • Convergence données/voix sur un même réseau
  • Fonctionnalités avancées (conférence, enregistrement, transfert)
  • Scalabilité facile
  • Intégration avec d'autres services (email, CRM)

2. Protocoles VoIP

2.1 SIP (Session Initiation Protocol)

SIP est le protocole de signalisation utilisé pour établir, modifier et terminer les sessions multimédia. C'est le protocole le plus utilisé en VoIP.

  • INVITE : Initier un appel
  • ACK : Confirmer la réception
  • BYE : Terminer un appel
  • REGISTER : Enregistrer un téléphone auprès du serveur
  • OPTIONS : Vérifier les capacités

2.2 RTP (Real-time Transport Protocol)

RTP transporte le flux audio/vidéo réel après l'établissement de la session SIP. Il fonctionne sur UDP pour minimiser la latence.

2.3 SRTP (Secure RTP)

Version chiffrée de RTP pour sécuriser les communications vocales.

4. Composants VoIP

4.1 PBX (Private Branch Exchange)

Central téléphonique gérant les appels internes et externes d'une entreprise.

PBX Logiciels

  • Asterisk : PBX open-source le plus populaire
  • FreePBX : Interface graphique pour Asterisk
  • 3CX : PBX commercial avec interface web
  • Microsoft Teams : PBX cloud intégré

4.2 IP Phones

Téléphones compatibles SIP qui se connectent directement au réseau IP.

  • Cisco IP Phone 7800/8800 series
  • Polycom VVX series
  • Yealink T-series
  • Grandstream GXP series

4.3 ATA (Analog Telephone Adapter)

Convertisseur permettant d'utiliser des téléphones analogiques existants sur un réseau VoIP. Exemple : Cisco PAP2T.

5. Configuration FreePBX

# Installation de FreePBX sur Debian/Ubuntu
sudo apt update && sudo apt install -y asterisk asterisk-core-sounds-en

# Configuration sip.conf (Asterisk)
[general]
context=from-external
allowoverlap=no
udpbindaddr=0.0.0.0:5060
tcpenable=yes
tcpbindaddr=0.0.0.0:5061
transport=udp

[1001]
type=friend
host=dynamic
secret=MonPassword123
context=from-internal
disallow=all
allow=ulaw
allow=alaw
qualify=yes

# Créer un extension dans FreePBX GUI
# Applications -> Extensions -> Add Extension
# Numéro: 1001, Secret: xxx, Device: SIP

7. Outils de test et diagnostic

Wireshark

Capturer et analyser les flux SIP/RTP. Filtrer avec sip ou rtp comme protocole. Vérifier les codes de réponse SIP (200, 404, 408, etc.).

SIPp

Outil de test de performance pour serveurs SIP. Simuler des milliers d'appels simultanés.

FreePBX

Interface web pour gérer Asterisk. Dashboard, logs d'appels, enregistrements.

9. Conseils

Toujours vérifier la qualité réseau (QoS) avant de déployer VoIP. La voix nécessite un débit stable et une latence < 150ms.
Un mauvais réseau peut causer de la distorsion, des coupures, et des délais dans les appels VoIP.
