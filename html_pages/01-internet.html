1. Qu'est-ce qu'un ISP ?

Un ISP (Internet Service Provider) est une entreprise qui fournit un accès à Internet à ses clients. Matrix Telecom est un ISP basé à Yaoundé, Cameroun. En tant qu'ISP, Matrix Telecom achète de la bande passante auprès de fournisseurs amont (upstream providers) comme MTN Cameroon, Camtel, ou CAMTEL-CI, puis la redistribue à ses clients (entreprises, particuliers, institutions).

2. Adressage IP

2.1 IP Publique vs IP Privée

Chaque appareil connecté à Internet a besoin d'une adresse IP. Il existe deux types d'adresses :

Adresses IP Publiques

Uniques dans le monde entier, attribuées par les fournisseurs d'accès. Elles permettent la communication directe sur Internet.

  • IPv4 : Format xxx.xxx.xxx.xxx (ex: 41.89.25.1)
  • IPv6 : Format xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  • Réservées aux équipements sur le réseau public

Adresses IP Privées

Utilisées dans les réseaux locaux (LAN). Non routables sur Internet.

  • Classe A : 10.0.0.0 — 10.255.255.255 (masque /8)
  • Classe B : 172.16.0.0 — 172.31.255.255 (masque /12)
  • Classe C : 192.168.0.0 — 192.168.255.255 (masque /16)

2.2 NAT (Network Address Translation)

Le NAT est une technique qui permet à plusieurs appareils d'un réseau local de partager une seule (ou plusieurs) adresse(s) IP publique(s). C'est essentiel car les adresses IPv4 sont limitées.

Chez Matrix Telecom, le NAT est configuré sur les routeurs MikroTik/Cisco pour permettre à des dizaines de clients d'accéder à Internet via un seul bloc d'adresses publiques.

3. DNS et DHCP

3.1 DNS (Domain Name System)

Le DNS est le système qui traduit les noms de domaine (ex: www.google.com) en adresses IP (ex: 142.250.78.206). C'est l'annuaire d'Internet.

  • Resolveur DNS : Premier serveur contacté par l'appareil
  • Serveur Racine (Root) : Pointe vers les serveurs TLD (.com, .fr, .cm)
  • Serveur TLD : Pointe vers les serveurs autoritaires du domaine
  • Serveur Autoritaire : Fournit l'adresse IP finale

3.2 DHCP (Dynamic Host Configuration Protocol)

Le DHCP attribue automatiquement une adresse IP, un masque, une passerelle et un serveur DNS aux appareils du réseau local. Le processus suit 4 étapes : DORA (Discover, Offer, Request, Acknowledge).

Chez Matrix Telecom, le serveur DHCP est généralement configuré sur les routeurs MikroTik (via WinBox). Chaque VLAN a son propre pool d'adresses.

4. Bande Passante, Latence et Perte de Paquets

Bande Passante (Bandwidth)

La quantité maximale de données pouvant être transférée par seconde. Mesurée en Mbps ou Gbps.

  • Entrée (Download) : 10 Mbps, 50 Mbps, 100 Mbps
  • Sortie (Upload) : 5 Mbps, 20 Mbps, 50 Mbps
  • Ex: Un client Matrix Telecom entreprise peut avoir un lien 100/50 Mbps

Latence (Ping)

Le temps de trajet aller-retour d'un paquet de données. Mesuré en millisecondes (ms).

  • < 20ms : Excellent (jeux en ligne, VoIP)
  • 20-50ms : Bon (usage général)
  • 50-100ms : Acceptable (navigation web)
  • > 100ms : Mauvais (retards perceptibles)

Perte de Paquets (Packet Loss)

Le pourcentage de paquets qui n'arrivent pas à destination. Idéalement 0%.

  • 0-1% : Normal
  • 1-3% : Problématique pour la VoIP/vidéo
  • > 5% : Inacceptable, connexion instable

5. Outils Réseau Essentiels

Wireshark

Analyseur de protocoles réseau. Capture et décode le trafic en temps réel.

  • Utilisation : Sélectionnez l'interface réseau → cliquez "Start" → filtrez avec tcp.port == 80 ou dns
  • Cas d'usage Matrix : Diagnostiquer les problèmes de connexion, analyser le trafic VoIP (SIP/RTP)
  • Téléchargement : wireshark.org
Ping

Teste la connectivité et mesure la latence vers une cible.

  • Utilisation : ping -t 8.8.8.8 (Windows) ou ping 8.8.8.8 (Linux/Mac)
  • Interprétation : Temps en ms, TTL (Time To Live), % de perte
  • Cas d'usage : Vérifier si un serveur est accessible, mesurer la latence vers un upstream
Traceroute

Affiche le chemin (route) pris par les paquets pour atteindre une destination.

  • Utilisation : tracert google.com (Windows) ou traceroute google.com (Linux)
  • Cas d'usage : Identifier où se situe un problème réseau (quel hop est lent ?)
Speedtest

Teste la bande passante réelle (download/upload) de votre connexion.

  • Utilisation : speedtest.net ou speedtest-cli
  • Cas d'usage Matrix : Vérifier que les clients reçoivent la bande passante承诺ée
MikroTik WinBox

Interface graphique pour configurer et monitorer les routeurs MikroTik.

  • Utilisation : Connexion par MAC ou IP → onglets Interfaces, IP, Queues
  • Cas d'usage Matrix : Configuration quotidienne des routeurs, gestion des queues (limitation de débit)
  • Téléchargement : mt.lv/winbox
