1. Définition

L'IPLC (International Private Leased Circuit) est une connexion privée dédiée entre deux sites distants, souvent dans des pays différents. Contrairement à Internet, le trafic IPLC est privé et sécurisé, traversant un réseau backbone dédié du fournisseur.

Différence entre Internet et IPLC

CritèreInternetIPLC
ConnexionPartagée (public)Dédiée (privé)
SécuritéVariableÉlevée
Bande passanteBest effortGarantie (SLA)
LatenceVariablePrévisible
CoûtÉconomiqueÉlevé
UsageNavigation, emailDonnées critiques, VoIP inter-site

2. Clients IPLC typiques

  • Banques : lien sécurisé entre siège et agences
  • Ambassades : communication diplomatique sécurisée
  • Entreprises multinationales : interconnexion des sites
  • Compagnies de télécoms : backbone interurbain
  • Gouvernements : réseau administratif sécurisé
Chez Matrix Telecom, les clients IPLC sont principalement des entreprises et institutions qui ont besoin de transmission sécurisée et fiable entre sites.

3. Technologies sous-jacentes

3.1 MPLS (Multiprotocol Label Switching)

MPLS est la technologie backbone utilisée pour transporter le trafic IPLC. Au lieu d'analyser l'entête IP à chaque saut, MPLS utilise des labels pour router les paquets rapidement.

┌──────────┐ MPLS ┌──────────┐ MPLS ┌──────────┐ │ Site A │◄──────────►│ Backbone │◄──────────►│ Site B │ │ (Yaoundé)│ Label:10 │ MPLS │ Label:20 │ (Douala) │ └──────────┘ └──────────┘ └──────────┘

3.2 Lignes louées (Leased Lines)

Connexion dédiée physique (copper ou fibre) entre deux points. Bande passante garantie 24h/24, 7j/7.

3.3 SLA (Service Level Agreement)

Contrat garantissant des métriques de qualité :

  • Disponibilité : 99.9% ou plus
  • Temps de réponse : < 50ms
  • Taux de perte de paquets : < 0.1%
  • Temps de réparation : < 4 heures

5. Configuration MikroTik pour MPLS/IPLC

# Activer MPLS sur MikroTik
/ip route vrf
add name=CUSTOMER_A rd=65000:1 import-route-target=65000:1 \
    export-route-target=65000:1

# Configurer le routeur MPLS
/mpls ldp
set enabled=yes lsr-id=10.0.0.1 transport-address=10.0.0.1

# Ajouter les interfaces au MPLS
/mpls ldp interface
add interface=ether1

# Configuration du tunnel VPN pour le client
/interface gre tunnel
add name=iplc-client-a remote-address=203.0.113.1 \
    local-address=198.51.100.1 mtu=1400
